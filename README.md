# MangoCare AI browser demo

[Open the demo](https://aditya070750.github.io/MangoCare-AI/).

Detection and classification run in the browser using the included LiteRT models. Detection history is stored in the current browser. Photos stay on the device.

The [main branch](https://github.com/Aditya070750/MangoCare-AI/tree/main) contains the Flask desktop version, training notebooks, and model checkpoints. See [LICENSE](LICENSE).
